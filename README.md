# Сокращения ГОСТ — надстройка для Microsoft Word

Находит в документе сокращения и обозначения, проверяет их по стандарту и собирает перечень. Бесплатно, с открытым кодом.

Поддерживаемые стандарты:
- ГОСТ 7.32-2017 (отчёт о НИР);
- ГОСТ Р 7.0.11-2011 (диссертация);
- ГОСТ Р 2.105-2019 (текстовые документы ЕСКД).

## Установка

1. Скачайте `AbbrGOST_vX.Y.zip` из последнего [релиза](../../releases/latest).
2. Распакуйте архив и закройте Word.
3. Запустите `Установить.cmd`.
4. В Word появится вкладка «Сокращения ГОСТ». Нажмите «Проверить».

Нужен Word для Windows с включёнными макросами (хотя бы «Отключить все макросы с уведомлением»).

## Что умеет

- **Панель рядом с текстом:** список сокращений со статусом, переход к первому упоминанию, карточка с замечаниями и полем расшифровки.
- **Проверки:**
  - расшифровка при первом упоминании;
  - повторные и разные расшифровки;
  - разнобой написания (ПЛК / Плк);
  - смешение латиницы и кириллицы (ПЛK);
  - соответствие перечню.
- **Перечень:** предпросмотр, сортировка (кириллица → латиница → обозначения), оформление по п. 6.15 ГОСТ 7.32-2017, вставка в место, которое требует стандарт.
- **Обозначения и словарь:** обозначения величин хранятся в документе, личный словарь и исключения — в `%APPDATA%\AbbrGOST`.
- **Отмена:** все правки вносятся в режиме исправлений и отменяются через Ctrl+Z.

## Сборка из исходников

```bash
pip install oletools python-docx
python3 build.py                       # → out/AbbrGOST.dotm
python3 make_release.py vX.Y           # → dist/AbbrGOST_vX.Y.zip
```

| Путь | Назначение |
|---|---|
| `src/` | код модулей VBA, панели и ленты |
| `base/` | контейнеры, созданные Word: основа сборки |
| `build.py` | сборка `AbbrGOST.dotm` |
| `ovba.py` | форматы MS-OVBA и MS-CFB, перекодировка строк |
| `make_release.py` | архив для релиза: надстройка, установщик, тестовый отчёт |
| `make_testdoc.py` | тестовый отчёт с типовыми ошибками |
| `sanitize_base.py` | очистка контейнеров Word от личных данных |
| `release-notes/` | описания версий |

`build.py` берёт проект и форму из контейнеров Word (`base/`) и подставляет исходный код модулей. Скомпилированный p-code удаляется, и Word перекомпилирует проект при открытии.

Исходники хранятся в UTF-8. Русские строки при сборке перекодируются в вызовы `U("...")`, поэтому надстройка не зависит от системной кодировки Windows.

Если обновляете файлы в `base/`, сначала очистите их: `python3 sanitize_base.py base/*`.

## Выпуск версии

Добавьте в `main` файл `release-notes/vX.Y.md`. GitHub Actions соберёт надстройку, проверит, что в ней нет личных данных, поставит метку и опубликует релиз. Уже опубликованные версии пропускаются.
