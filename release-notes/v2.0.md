Панель рядом с текстом вместо отчёта, окон ввода и сообщений.

- Список сокращений со статусом; щелчок по строке переносит курсор к первому упоминанию.
- Карточка выбранного сокращения: все замечания, поле расшифровки, кнопки «Вставить расшифровку в текст», «Исправить написание», «В словарь», «Не проверять».
- Вкладка «Перечень»: предпросмотр, правка строк, запись в документ.
- Вкладки «Обозначения» и «Словарь» с поиском.
- «Исправить всё» — для всего документа сразу. Все правки вносятся в режиме исправлений, отмена — Ctrl+Z.

**Установка:** распакуйте архив, закройте Word, запустите «Установить.cmd». Прежняя версия сохраняется, вернуть её можно через «Вернуть прежнюю версию.cmd».

**Требования:** Microsoft Word для Windows с включёнными макросами (хотя бы «Отключить все макросы с уведомлением»).
